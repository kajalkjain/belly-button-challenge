# belly-button-challenge
Module 14 Challenge - Interactive dashboard

Instructions
Complete the following steps:

Use the D3 library to read in samples.json from the URL https://static.bc-edx.com/data/dla-1-2/m14/lms/starter/samples.json. Completed

Create a horizontal bar chart with a dropdown menu to display the top 10 OTUs found in that individual. - Completed

Use sample_values as the values for the bar chart. - Completed

Use otu_ids as the labels for the bar chart. - Completed

Use otu_labels as the hovertext for the chart. - Completed

Create a bubble chart that displays each sample. - Completed

Use otu_ids for the x values. - Completed

Use sample_values for the y values. - Completed

Use sample_values for the marker size. - Completed

Use otu_ids for the marker colors. - Completed

Use otu_labels for the text values. - Completed

Display the sample's metadata, i.e., an individual's demographic information.
Loop through each key-value pair from the metadata JSON object and create a text string.

Append an html tag with that text to the #sample-metadata panel.
